Setup

Three steps. About two minutes.

  1. 1

    Install Echo

    Download the installer and run it. No accounts, no admin rights, nothing to configure.

    Windows will warn you the first time. That's normal for any brand-new app: click More info → Run anyway. Want to check first? Every line of Echo's code is public on GitHub.
  2. 2

    Open your AI app

    Echo connects itself to Claude Desktop, Cursor, VS Code, Codex, OpenCode and 10+ other AI apps. If yours was already open, just restart it once.

  3. 3

    Just ask

    Try: “Open YouTube and find me a lofi playlist.” Your AI works in a real browser window — and you see every move it makes.

Why you can relax

Built to be boring about your data.

  • Open source. Every line of code is public — anyone can check exactly what it does.
  • Stays on your computer. No accounts, no tracking, no cloud. The only network call is checking for updates.
  • Never touches your personal browser. Echo keeps its own separate profile and its own data.
  • Removes cleanly. Uninstalling also disconnects it from every AI app automatically.

Questions

Good to know

Is it really free?

Yes — completely. If it becomes part of your workflow, you can support development on Patreon, but nothing is locked behind it.

Do I need to be technical?

No. If you can install an app and type a request, you're set. Echo exists exactly so you can skip the fiddly setup.

What's the Windows warning about?

Windows shows it for any new app that hasn't built up download history yet. Click More info → Run anyway. And you can verify Echo yourself — the entire source is public.

Which AI apps does it work with?

Claude Desktop, Claude Code, Cursor, VS Code, Codex, OpenCode, Windsurf, Cline, Roo Code, Gemini CLI, Qwen Code, Continue, Antigravity, and pi — with more over time.

Does it work on Mac or Linux?

Windows first. Mac and Linux are possible later — the code is open source, so anyone can help make it happen.

Where do downloads come from?

Straight from GitHub Releases — the same place updates come from.
