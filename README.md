# Echo website

Source of **https://echo-browser-for-ai.github.io/** — a single static page, no build step, no trackers, no external requests.

- `index.html` — the page
- `styles.css` — styles (one accent color, system fonts)
- `assets/` — logo

Edit any file and push to `main`; GitHub Pages redeploys automatically (about a minute).

Main project: https://github.com/echo-browser-for-ai/echo
